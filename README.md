# SurvivorLike

类吸血鬼幸存者的 2D 像素肉鸽 Demo。一个人，一个月，第一个完整项目。

Unity 2022.3 · C# · Windows
![gameplay](gameplay.gif)

## 玩法

方向键移动，鼠标左键射击，`E` 键拾取地面上的武器。

在 5 分钟内活下来：时间耗尽即胜利，血量清零则失败。

## 做了什么

- **双武器**：环绕旋转的近战铲子 + 鼠标瞄准的自动步枪
- **武器获取**：武器在地图上定时刷新，走进范围按 `E` 拾取装备
- **战斗反馈**：受击闪白、击杀计数
- **局流程**：限时生存 → 死亡 / 超时 → 结算 → 重开

约 750 行 C#，17 个脚本。

## 技术要点

**环绕武器没有用状态来驱动。**

常见写法是每帧 `angle += speed * deltaTime`，或者用 `RotateAround`——但那会累积浮点误差，
而且增删武器时所有相位都要重算。

这里改成参数化：

```csharp
angle = Time.time * rotateShovelSpeed * Mathf.Deg2Rad
      + index * 2 * Mathf.PI / totalCount;
```

位置直接由这个角度算出来，不保存任何角度状态。好处是：不漂移、增删武器自动均分、改速度不会错位。

## 运行

用 Unity 2022.3 打开本工程，载入 `Assets/Scenes` 下的场景运行。
